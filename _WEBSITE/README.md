# latechsmp.net

## What is this?
This is the source code for the Unoffical [Louisiana Tech Minecraft Server](https://latechsmp.net) website.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
